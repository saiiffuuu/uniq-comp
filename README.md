# UniQ Computers website

Responsive static website for UniQ Computers' CCTV and security services.

## Preview locally

Install the development dependency once, then start the local static server from this folder so the root-relative page and asset URLs resolve correctly:

```sh
npm install
npm run dev
```

Then open `http://localhost:8000`. You can also use `npm start`.

## Before publishing

- Company contact details for Anwar are configured in `script.js`; phone links use the India country code and WhatsApp opens the supplied mobile number.
- Add verified business hours, service coverage area, approved customer testimonials, and genuine project descriptions/locations/images.
- The projects, reviews, business details and product descriptions deliberately avoid claiming unverified facts; replace the marked placeholders only with approved information.
- Current photography is illustrative and loaded from Unsplash; replace it with approved company imagery when available.
- The inquiry form opens a prefilled email only after an email address is configured. It does not store submissions or send data to a server.
- Add the company's real social profile links in the footer when supplied.
